# Где найти ZIP-пакет для GitHub

Файл для скачивания:

```text
field01_github_upload_package.zip
```

Запасная копия лежит здесь:

```text
public_release/field01_github_upload_package.zip
```

Если Prism не показывает архив, обновите список файлов или перезапустите Prism.
В настройках отображения файлов должен быть разрешён шаблон:

```text
*.zip
```

После скачивания распакуйте ZIP и скопируйте его содержимое в папку репозитория `field01`, открытую через GitHub Desktop кнопкой `Show in Explorer`.
