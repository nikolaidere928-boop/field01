# Field 01 Four-Week Launch Plan

This plan is designed for an independent author with no existing academic network. The aim is not to prove the project in four weeks, but to create a credible public starting point, gather first criticism, and prepare a path toward collaboration.

## Guiding Principle

The first public goal is trust, not persuasion.

Do not present Field 01 as a finished theory. Present it as a cautious independent formalization program that needs criticism, comparison with known physics, and help from mathematically trained readers.

Recommended framing:

```text
I am an independent author developing a cautious toy-level formalization around phase circulation, closed nodes, normal retention, memory classes, and boundary recording. I am not claiming a completed physical theory. I am looking for criticism, comparison with known models, and advice on what must be formalized first.
```

## Week 1 — Make the Project Legible

Goal: make the project understandable to a stranger in 10 minutes.

### Tasks

1. Review and update `README.md`.
2. Make sure `PROJECT_ROADMAP_EN.md` is consistent with the current formalization paper.
3. Prepare one short entry document of 3--5 pages.
4. Choose one primary paper for first readers: probably `articles/field01_formalization_program_en.tex`.
5. Write a short personal project note explaining who you are and what kind of feedback you need.

### Deliverables

- public-facing `README.md`;
- short 3--5 page overview;
- clean PDF of the formalization paper;
- list of 10 concrete questions for critics.

### Success Criteria

By the end of week 1, a reader should be able to answer:

- What is Field 01 trying to formalize?
- What does it not claim?
- Which parts resemble known physics?
- What feedback is requested?

## Week 2 — Prepare the Public Archive

Goal: create a stable place where people can read the work without needing private messages.

### Tasks

1. Create a GitHub or GitLab repository.
2. Upload the project files in a clean structure.
3. Add a license or usage note for texts and code.
4. Add a `CONTRIBUTING.md` file explaining how people can comment or help.
5. Create a first version tag, for example `v0.1-public`.
6. Optionally archive the first public PDF package on Zenodo or OSF.

### Recommended Repository Structure

```text
README.md
PROJECT_ROADMAP_EN.md
FOUR_WEEK_LAUNCH_PLAN.md
FIELD01_GLOSSARY.md
OUTREACH_PACKAGE_EN.md
articles/
analysis/
chapters/
```

### Deliverables

- public repository;
- first public release;
- stable link to share;
- one PDF package for readers who do not use GitHub.

### Success Criteria

By the end of week 2, you should have one link that can be sent anywhere with the sentence:

```text
This is the current public working archive of Field 01. It is not a completed theory; I am looking for technical criticism and help with formalization.
```

## Week 3 — Ask Narrow Public Questions

Goal: get the first external reactions without overexposing the full project.

### Tasks

1. Prepare 3 small Reddit posts, each with one narrow technical question.
2. Do not post the whole theory at once.
3. Start with comparison questions, not claims.
4. Save useful comments and objections in a local notes file.
5. Revise the overview after feedback.

### Suggested Reddit Post 1

```text
Title: Is this toy radial phase model essentially an Abelian-Higgs/vortex model?

I am an independent author trying to formalize a cautious toy model with a phase variable phi, winding number, scalar radial profile N(r), and a gauge-like compensating field A_mu. I am not claiming a new physical theory. I want to understand how much of this is already standard Abelian-Higgs/vortex mathematics and what terminology I should avoid.

The current formalization uses objects like Q_wind = (1/2pi) integral d phi and a screened radial energy with (n-a(r))^2 N^2 / r^2. My question is: what is the closest standard model or reference I should study before developing this further?
```

### Suggested Reddit Post 2

```text
Title: How should an independent author phrase a speculative toy model without overstating it?

I am writing a cautious formalization draft around phase winding, scalar profiles, and boundary records. I explicitly state that it is not a replacement for QFT, GR, or the Standard Model. What phrases should I avoid so that the text does not sound like a crank theory? What is the most academically honest way to request criticism?
```

### Suggested Reddit Post 3

```text
Title: What mathematical structure fits a “memory as equivalence class” idea?

I am trying to formalize a speculative idea where preserved phase-scalar-gauge data with a normal-retention interpretation are treated as an equivalence class under gauge choice, coordinate representation, and smooth deformations preserving certain invariants. Are there standard mathematical frameworks I should compare this with before using this language?
```

### Recommended Communities

- `r/AskPhysics`
- `r/PhysicsStudents`
- `r/math`
- `r/learnmath`
- `r/TheoreticalPhysics`
- `r/LaTeX` for presentation questions only

### Success Criteria

By the end of week 3, success is not praise. Success is having:

- 5--10 concrete objections;
- 3--5 references or keywords to study;
- clearer language for the next draft;
- one or two people who respond seriously.

## Week 4 — Revise and Open the Door to Collaboration

Goal: turn criticism into a better version and invite low-pressure collaboration.

### Tasks

1. Create a feedback log: objection, source, response, action.
2. Revise `README.md`, the overview, and the formalization paper.
3. Add a `CONTRIBUTING.md` file if not already done.
4. Publish version `v0.2-feedback`.
5. Write a short update post explaining what changed because of criticism.
6. Invite help on specific tasks, not general belief in the project.

### Suggested Collaboration Requests

Ask for small, concrete contributions:

- check whether the screened energy is correctly related to Abelian-Higgs notation;
- suggest standard references for vortices and topological defects;
- critique the memory-as-equivalence-class language;
- identify claims that should be weakened;
- help reproduce numerical toy profiles;
- improve English scientific style.

### Success Criteria

By the end of week 4, the project should have:

- a public repository;
- a first stable PDF package;
- a clearer README;
- a list of known weaknesses;
- a revised draft shaped by criticism;
- a small number of people who may be willing to look again.

## What Not To Do In The First Four Weeks

- Do not ask strangers for arXiv endorsement immediately.
- Do not send the full book as a first contact.
- Do not claim a replacement for known physics.
- Do not argue defensively with critics.
- Do not post the same long manifesto in many communities.
- Do not hide similarities with known Abelian-Higgs or vortex structures.

## After Four Weeks

If the first month goes well, the next step is a three-month plan:

1. turn the formalization paper into a clean preprint-style manuscript;
2. add a reproducible numerical appendix;
3. build a comparison table with standard models;
4. prepare a Zenodo or OSF release;
5. only then consider asking whether the manuscript is appropriate for arXiv and which category fits.

## Personal Strategy

Because the author is independent and outside an academic network, credibility must be earned through process:

- cautious language;
- versioned documents;
- public corrections;
- willingness to weaken claims;
- visible comparison with known work;
- reproducible toy calculations;
- narrow, respectful questions.

The practical aim is to become someone whose work is easy to inspect and hard to dismiss as careless.
