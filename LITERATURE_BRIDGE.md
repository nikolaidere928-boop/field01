## How To Use This In the Public Project

The extracted literature should be used in three ways:

1. **Vocabulary alignment** — replace isolated Field 01 terms with standard terms where possible.
2. **Comparison sections** — explicitly say which parts match known structures.
3. **Citation support** — cite relevant literature before presenting interpretation.

## Style Rule

For each concept, write in this order:

```text
standard term -> standard reference -> Field 01 interpretation -> open hypothesis
```

Example:

```text
In standard vortex models, phase winding is represented by an integer winding number. Field 01 uses this standard structure as a toy representation of a closed phase node. The additional interpretation of winding as phase memory is model-specific and remains hypothetical.
```

### How This Changes the Writing Strategy

The public papers should now be revised in this order:

1. Introduce the standard term first: phase winding, vortex, Abelian-Higgs model, covariant derivative, field strength, Noether current.
2. Cite the closest standard reference.
3. Only then introduce the Field 01 interpretation: closed node, normal retention, memory, boundary recording.
4. Explicitly say which parts are standard and which are interpretive.

Example wording:

```text
The screened toy model uses the same mathematical ingredients that appear in Abelian-Higgs/Nielsen-Olesen vortex models: a phase winding, a scalar amplitude/profile, and a compensating gauge field. Field 01 does not claim novelty for this structure. It uses it as a controlled toy language for the interpretation of closed phase nodes, normal retention, and memory.
```
