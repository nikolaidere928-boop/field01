# Field 01

Field 01 is an independent research and writing project about a phase-based interpretation of particles, memory, and horizon-like boundary recording.

This repository is arranged as a calm reader-facing package. It is not a claim that Field 01 is a completed physical theory. The purpose is to present the current concept clearly enough for an external reader to understand what is being proposed, what is standard background, and what remains hypothetical.

## One-Sentence Summary

Field 01 explores whether selected particle-like and boundary-like structures can be described through phase circulation, scalar profiles, memory classes, and boundary maps.

## Basic Picture

At the conceptual level, the project uses two primitive modes:

- `0` — fixation, retention, boundary, recording, local depth;
- `1` — direction, motion, circulation, transport, unfolding.

The phrase “Field 01” refers to the proposed unity of these two modes.

In the current mathematical language, this idea is compared with familiar structures such as phase variables, winding, radial scalar profiles, gauge-like compensation, equivalence classes, and boundary descriptions. These comparisons are used cautiously: Field 01 terminology is interpretive unless a standard mathematical object is explicitly named.

## Current Limit

Field 01 should be read as a speculative conceptual framework under formalization, not as a replacement for the Standard Model, quantum field theory, or general relativity.

The most developed comparison layer currently resembles known vortex-like mathematics. In that standard layer, `N(r)` should be read first as a radial scalar modulus or order-parameter profile. Field 01 labels such as `normal retention`, `memory`, and `boundary recording` belong to the interpretation layer.
