# License and Usage Note

Release note: this remains a temporary usage notice. A formal license choice is still required before final publication.

This project is currently shared as an independent working archive for criticism, discussion, and formalization.

A precise long-term license has not yet been chosen. Until a formal license is added, please treat the material as follows.

## Texts and Papers

The written materials, including papers, overview documents, roadmap files, glossary entries, and overview and roadmap files, are shared for reading, criticism, quotation, and discussion.

If you quote or discuss substantial parts of the text, please credit the author and refer to the project as Field 01.

Do not republish large portions of the book, papers, or project texts as your own work.

## Code and Numerical Scripts

The numerical scripts are shared to make the toy calculations inspectable and reproducible.

You may read, run, and critique the scripts. If you reuse substantial parts of the code in another public project, please credit Field 01 and link back to the source repository once it is public.

## Figures and Data

Generated figures, CSV files, and JSON files are included only as toy-model outputs unless stated otherwise.

They should not be presented as experimental data or as proof of a physical theory.

## No Endorsement

Criticism, comments, or contributions by external readers do not imply endorsement of Field 01.

The project explicitly welcomes disagreement and correction.

## Future License

Before wider distribution, the project should choose a clearer license policy, for example:

- a Creative Commons license for texts;
- an open-source license for code;
- or a more restrictive rights-reserved policy for the book manuscript.

Until then, this note is intended as a temporary usage guideline rather than a full legal license.
